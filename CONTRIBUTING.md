# Contributing to romm-steam-sync

Thank you for your interest in contributing to `romm-steam-sync`! In this very early state I'm not yet accepting contributions, but once we're in a more stable place this doc will be updated with guidelines for contributing.

---

## Reporting Issues

Before opening a bug report or feature request on GitHub, please review the following:
- Check existing GitHub issues and discussions to avoid duplicate reports.
- If reporting a game launch failure, **verify that the game launches successfully directly inside RetroArch or RetroDECK** outside of Steam and `romm-steam-sync` before submitting the issue.
